# 基本功能

开始学习线段树喽！
单次调用的时间复杂度为 $O(log n)$
1. 范围查询，包括范围内累加和，最大值，最小值等等信息
2. 范围修改，包括范围内每个数都增加，重置等操作

判断范围修改能否做到$O(logn)$ ,需要判断对整个范围的统一操作是否能做到 $O(1)$。如果可以则能用线段树维护。
1. 符合要求： 区间每个值增加 x ，整个范围直接 $+ x\times cnt$ 即可。
2. 不符合要求：区间每个值逆序，$123\longrightarrow321$ , 需要对每个值特殊修改再统一计算整体。

懒标记：
用于区间修改，如果不是区间修改则可以不用 懒标记。
懒标记核心：
- 这个节点的懒标记表示 对下一个节点的 任务，且该节点本身已经完成该任务。
- 懒标记 在 下放 的过程中，要记得 和子节点原有懒标记进行叠加，而非删改。
