# 前缀数组与 KMP

## 前缀函数
给出字符串，计算出这个字符串的前缀数组
`f[i]`  表示 满足以第 i 个字符结尾的这个字符串前缀 所形成的 字符串 的 最长 公共 前后缀 的长度

### 讲解：
递推过程如图：
简单来说，就是利用上个位置的前缀函数 做dp
固定 以 i 为结尾中，后缀的 前面几个是不变的，为了找最长，一定是找 i - 1 的最长     公共前后缀 并且 满足 i 位置 和对应前缀位置相同。

待补图片（Pasted image 20260809184109.png）


### Code(模板)：
```cpp
vi pi(s.size()),ans;
for(int i=1;i<s.size();++i)
{
	int len=pi[i-1];
	while(len&&s[i]!=s[len]) len=pi[len-1];
	pi[i]=len+(s[i]==s[len]);
}
// 时间复杂度 接近O(n)
```
## KMP 算法
目的：
给定一个主串，你给出匹配串 要求在主串中找到一样匹配串的子串位置

### 讲解：
实际上，kmp 就是 将模式串 和 主串结合 再求这个新的字符串的前缀数组的过程
如 "ATAATA" 为匹配串 ， "AGCATAATAATTAA" 为主串

待补图片（Pasted image 20260809183955.png）


很明显，前缀函数 `pi[i]` 等于 匹配串长度 的位置，就是符合条件的子串 结尾的位置。
