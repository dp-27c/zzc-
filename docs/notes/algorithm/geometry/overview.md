# 计算几何前瞻摘记

## 计算几何的两大流派：
1. 旋转平移流（通过平移和旋转坐标系来简化问题，适用于没有板子的oi爷）
2. 板子流（通过封装一个类，给出接口并利用接口完成问题，适用于acmer）

## 模版
### 常见原素：
- 点（坐标）
- 线（两个点，方向）
- 圆（点，半径）
### 单元操作：
- 点到直线的投影
- 直线/圆 和 直线/圆 的交点
- 点/圆 到 圆 的切线
- 点 和 多边形的位置关系

### 凸包的快速操作：
- 求凸包
- 旋转卡壳
- 点到凸包的切线（以及位置关系）
- 直线和凸包的交点
- 闵可夫斯基之和
## 插入一个 trick 
> 判断点与多边形的内外关系：
> 射线 交 点 法：
> 	在点上沿着任何一个方向发射一条射线，每次穿过多边形的一条边都意味着 点位置在多边形内外的翻转 
>

此时我们可以引入两个方法：
1. 所有点随机旋转 $\alpha$ 度，这样的坏处就是精度上不高
2. 随机射一条 旋转 $\alpha$ 度的射线，需要额外写射线 与 多边形的交 代码。
3. 这个方法（没听懂啊）
目的都是在于减少出现特殊情况的概率。
