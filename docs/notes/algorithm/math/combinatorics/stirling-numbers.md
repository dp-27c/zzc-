## 第二类斯特林数/ 斯特林子集数：


### 公式+理解：

这类斯特林数通常表示： $\huge S_{n}^{m}$

对于有着 n 个元素的一个集合划分成 m 个非空集合的方案数

将 n 个小球 放到 m 个盒子里，保证每个盒子都不是空的。

注意：前提是保证了 m 个集合是统一性的。 例如：
m个房子，m个相同的盒子
否则还需要的对 m 做全排列
递推式：
$\huge S_{n}^{m}=S_{n-1}^{m-1}+m*S_{n-1}^{m}$

## 第一类斯特林数/斯特林轮转数（0）


***将 n 个元素划分成 m 个非空圆排列 的方案数***

### 公式：


$\huge S_{n}^{m}=S_{n-1}^{m-1}+(n-1)*S_{n-1}^{m}$

设立初值：

$\huge S_{0}^{0}=1,S_{1}^{0}=0$

注意和第二类斯特林数是不一样的，至于为什么都叫斯特林数，你问问那个AI ？
**还有 斯特林轮转数 的增长比 第二类斯特林数还大**

***将 n 个元素划分成 m 个非空圆排列 的方案数***
注意： 这里的圆排列不一定非要是圆，你可以抽象成一个确定了一个位置的n的全排列：$\large (n-1)!$

### 练习：


#### 思维判断 斯特林轮转数

[P4609 [FJOI2016] 建筑师 - 洛谷](https://www.luogu.com.cn/problem/P4609)
这题是一道思维题：
重点在于，是如何将问题抽象成可以用斯特林来理解的。
大意：
有 n 个建筑，建筑的高度满足 n 的排列。
如果这个建筑的排列满足 从左边看 有 a 个 建筑吗从右边看 有 b 个建筑，则这个排列是合法的 。
求出合法排列的数量。
T为测试数据。
对于 100% 的数据 ：1≤n≤50000, 1≤A,B≤100, 1≤T≤200000。
思路：
首先，我们知道，对于最高的建筑 （高度为n） 来说，无论如何都会被看见，那么我们可以看成 这个高度为 n 的建筑，将排列分成了左右两个部分。

对于这两个部分而言，左边 a -1 个可以被观测，右边 b - 1 个可以被观测。

我们可以将能被观测的那个建筑为首，排在它后面的且比他小的建筑合在一起看成这样的建筑群，下图将不同的建筑群用不同的颜色做了标记。
每个建筑群可以看成是一个圆排列，因为确定了最高的建筑的位置一定在排列的端点处，所以剩下元素就是一个全排列。

那么问题就变成了 ，我 有n - 1 个数，将这些划分成 ( a - 1 ) + ( b - 1 ) 个圆排列。即斯特林轮转数：`S[n-1][a+b-2]`
。
分完这 a + b - 2 个圆排列后，选择其中 a - 1 个放左边就行了，因为放在一边圆排列之间 的 排列 的位置是递增的，保持可观测，所以不用乘上排列的顺序。即只要乘上`C[a+b-2][a-1]`.

答案 `S[n-1][a+b-2] * C[a+b-2][a-1]`
注意取模。这题就不会用什么 模不是质数，高精度来恶心你，就考你思维的转换，以及组合数学的熟练度，是个良心好题！！

![用第一类斯特林数求解练习的推导](../../../../assets/note-images/Pasted%20image%2020250821164945.png){width=1112 height=482}

```cpp
vii S(5e4+7,vi(201,0)),C(201,vi(201,0));
void init()
{
    S[0][0]=1,C[0][0]=1;
    int a=100,b=100,n=5e4+5,m=200;
    rep(i,1,a+b)
    {
        rep(j,0,i)
        {
            if(j==0){C[i][j]=1;continue;}
            C[i][j]=(C[i-1][j-1]+C[i-1][j])%mod;
        }
    }
    rep(i,1,n)
    {
        rep(j,1,m)
        {
            if(j>i) break;
            S[i][j]=(S[i-1][j-1]+((i-1)*S[i-1][j])%mod)%mod;
        }
    }
}
int M;
void solve() // ll !
{
    int n,a,b;cin>>n>>a>>b;
    cout<<(S[n-1][a+b-2]*C[a+b-2][a-1])%mod<<endl;
}
```
