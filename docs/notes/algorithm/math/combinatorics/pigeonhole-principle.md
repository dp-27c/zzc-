# 鸽笼原理：

数学上很简单，就是5只鸽子放四个笼子，必然有一个笼子里含有两只鸽子
但是问题缺很复杂
问了一下学长才知道，这题思考要转一转：

[Problem - D - Codeforces](https://codeforces.com/contest/2120/problem/D)
这题就是一道复杂的鸽笼原理：
大意：
给定一个 a * b 的矩阵大小，问你用至少多大的矩阵才能保证一定能找到一个子矩阵 （ a * b )  满足其中的元素相等，矩阵的元素在 1->k 之间的整数。
找到的矩阵满足所有符合条件的矩阵中 (n,m)的字典序最小。

思路：
为了符合字典序最小，所以我们先判断行，为了保证能够找到 至少  a  个相同元素的行 ， 所以我们至少需要 $\large (a - 1) * k + 1$  个这样的行
这样的做法是为了保证每行只放一个元素的这种策略失效，后续列的判断不能以这种策略为前提。
此时确定了  n = $\large (a - 1) * k + 1$ 行。
