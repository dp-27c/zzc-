# 圆排列：（0）

n个不同的数，围成一圈的圆排列数，记做：$\huge Q_{n}^{n}$
递推公式：
$\huge Q_{n}^{n}=\displaystyle \frac {A_{n}^{n}}{n}=(n-1)!$

$\huge Q_{n}^{m}=C_{n}^{m}*Q_{m}^{m}$
第二个就很像排列数与组合数的推理了。

## 理解：


第一个公式为什么？如何理解呢？
考虑断环成链，对于同一个圆排列，n 个 地方可以断环，并且断完后，每个排列都是不同的，全部的加起来就是一个排列数，所以是排列数除以n：

## 拓展理解：


既然圆排列满足这个公式
$\huge Q_{n}^{n}=\displaystyle \frac {A_{n}^{n}}{n}=(n-1)!$
我们还能将其他满足这个公式的数也看成圆排列：
对于n个数来说，我们确定一个数的位置，剩下的数进行全排列，这样的排列也可以是圆排列。
这样我们能更方便的使用斯特灵轮转数进行推导。
