# Nim游戏



## 简单Nim游戏策略

用异或和来模拟游戏策略
思路关键：找出了一个先手必输的状态，通过策略到达这个状态
eg:
题意：有n堆石子，第 i 堆石子有 $a_i$ 个石头。
两个人轮流取石子，每个人只能在其中一堆取，可以取任何个数，但不能不取。
最后没得取的人输
问：先手 是必胜 还是必输。

思路：
对于思考这个问题，我们要理解最后的状态：0 0 0 0 0 0 的时候，那个人就会输。
不难看出，对于两堆石子，如果两堆初始不一样，7 5 。那我就第一堆拿两个，变成 5 5.此时无论后手怎么拿，我维持两者相同就好了。
但是从这里推广，就发现无从下手了，三堆的策略怎么模拟呢，四堆又怎么模拟呢。发现不太好找到一个万能的策略。
我们回到 0 0 0 0 0 的状态本身，除了每堆石子都是0个以外，找到每位二进制之和为偶数。
从这一点出发，发现在0 0 0 0 0 本身，在某一堆加上任意大于0的石子个数，就会存在至少一位二进制之和 为奇数。破坏了这个最终状态，同时，我们再从某一堆增加相应的石子数，使得每位二进制之和为偶数。这就可以成为策略。

对于每位二进制之和为奇数的 n 堆石子，我只要拿走石子，使得每位二进制之和为偶数。那么后手无论怎么改变，我都可以利用这个方法，保持我拿完后，每位二进制数之和为偶数。先手必胜。

相反，如果n堆石子本身已经是每位二进制之和为 偶数的石子，那先手就不得不破坏其奇偶性，那此时后手就变成了上一条的先手，从而必胜。先手必输。

答案已经很明显了，每位二进制之和是否都是偶数的判断可以用 异或和。



模版题：
[P2197 【模板】Nim 游戏 - 洛谷](https://www.luogu.com.cn/problem/P2197)
```cpp
void solve() // ll
{
    int n;cin>>n;
    int s=0,m;
    rep(i,1,n)cin>>m,s^=m;
    cout<<(s?"Yes\n":"No\n");  
}
```


## 反Nim博弈：

[P4279 [SHOI2008] 小约翰的游戏 - 洛谷](https://www.luogu.com.cn/problem/P4279)
思路关键：找到一个先手必胜的状态，然后策略达到这个状态。
大意：
题意：有n堆石子，第 i 堆石子有 $a_i$ 个石头。
两个人轮流取石子，每个人只能在其中一堆取，可以取任何个数，但不能不取。
取到最后一个石子的人输。
问：先手 是必胜 还是必输。

思路：
分类情形：
1. 当每堆状态只有 1 的时候，那么每次只能将一堆中取走1，显然奇数堆必输，偶数堆必胜。
2. 存在一个堆，石子数大于1，并且其他堆的式子都是1，此时发现，我可以通过取大于1的那一堆，要么剩下1，要么全部取走，从而使得最后剩下的堆的石子数满足 情形1 的奇数堆个1，从而先手必胜。
3. 当有多个大于1的堆的时候，我们理解，情形2时，这个必胜状态属于异或和一定大于0，相反如果异或和等于0则一定不是这个状态。那么对于多个堆的时候，我们控制，使得每次我操作完后，异或和为0，那么我以外的后手就一定不会进入这个情形2的状态。
因为每次取石子，数量不断变小，最终一定会有情形2的状态，而且这个状态一定是那个维护使得后手异或和保持0的那个人。

由这个策略可知：
特判情形1，即是否全1堆。
否则，求异或和，如果异或和大于0，则先手必胜，等于0则先手必输。


Code:
```cpp
void solve() // ll
{
    int n;cin>>n;
    int s=0,cn1=0;
    rep(i,1,n)
    {
        int x;cin>>x;
        if(x==1) cn1++;
        s^=x;
    }
    if(cn1==n) // 特判
    {
        if(cn1&1) s=0;
        else s=1;
    }
    if(s)
    {
        cout<<"John\n";
    }
    else cout<<"Brother\n";
}
```
