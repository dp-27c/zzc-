# 计算几何

## 轴上圆内点的处理：
[Problem - D - Codeforces](https://codeforces.com/contest/2074/problem/D)
大意：
粉色士兵在飞机的x轴上画了以圆心为中心的圆圈。同样，他们告诉，半径的和正好是 m  。
请找出至少一个圆内或圆边的整数点的个数。问题的正式定义如下。
给定一个整数序列 $x_1,x_2,\dots,x_n$ 和一个正整数序列 $r_1,r_2,\dots,r_n$，其中已知 $\sum_{i=1}^n r_i=m$。
必须统计满足以下条件的整数对 ( x, y ) 的个数。
—存在索引 $i$（$1\le i\le n$），满足 $(x-x_i)^2+y^2\le r_i^2$。
这些信息真的有用吗？别问我；我真的不知道

1≤n≤m≤2⋅1e5
思路：
其实不太好想，容易被这圆的几何思维给误导，我们考虑如何从 半径和为 m 的这个信息作为切入点。
首先如果每个元单独计算的话，那么我们还要考虑相交的部分，导致时间复杂和算法复杂爆炸。

因为半径和的范围不会很大，且圆心都在 x 轴上，我们是否可以考虑从 圆的最左边遍历到圆的最右边，同时，x轴上圆内的点满足，
到圆心的距离小于半径，而以这个x轴上的这个点为横坐标的点满足 $\large y\le\sqrt{r^2-d_x^2}$.

因此我们可以线性遍历 一个圆的左边到右边来算出 这个横坐标上有多少个点在圆内，且枚举的半径只有 2e5.总共的枚举也才 4e5.

那么我们考虑重复相交问题，很简单，即最大值就好了。用 map 桶来存每个涉及到的 横坐标 的包括范围的点的个数的最大值。
最后求他们的和就好了
