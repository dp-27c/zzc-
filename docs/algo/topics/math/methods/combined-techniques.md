# 缝合怪

## 概率期望+范德蒙卷积公式+二项式反演+斯特林反演+NTT
[P2791 幼儿园篮球题 - 洛谷](https://www.luogu.com.cn/problem/P2791)

融合了这么多元素，想不黑都难啊
难在前置知识太多了，但是前置知识都会，那么就能看的懂题解
大意：
全民制作幼儿园的蔡徐坤专属篮球场上总共有 N 个蔡徐坤专属篮球，而其中有 M 个是没气的。鉴于蔡徐坤的高超技术，他投**没气的球一定能进**，而投**有气的球一定不能**。
蔡徐坤举办了 S 场巡回篮球表演，第 i 场表演 ikun 们会指定投球个数 ki​ ，ikun 们会从 N 个蔡徐坤专属篮球中准备 ni​ 个球放在场地上，其中恰好有 mi​ 个是没气的。蔡徐坤会在这 ni​ 个蔡徐坤专属篮球中**随机**选出 ki​ 个投篮。如果投进了 x 个，则这次表演的**失败度**为 xL。ikun 们想知道这 S 场表演的**期望失败度**对 998244353 取模的结果。篮球表演之间**相互独立**。
对于全部数据，1≤S≤200，1≤L≤2×1e5，1≤M≤N≤2×1e7。并且对于 1≤i≤S，有 1≤mi​,ki​≤ni​≤N，1≤mi​≤M。
思路：
- 根据题意我们列出每次巡演的期望公式：

$$
\Large E(x)=(\sum_{i=0}^{k} C_{m}^{i}\ C_{n-m}^{k-i}\ i^L )/C_{n}^{k}
$$

如果直接算，那么就会变成 $O(ns)$ 超过 1e9 了，所以考公式变形优化。
这里漏了一点，因为这里有 $i^L$ 计算ksm需要时间 放在这里面是致命的。
这个 $j^n$ 太难看了，用斯特林反演处理掉
$\Large \displaystyle \sum_{i=0}^{k} C_{m}^{i}\ C_{n-m}^{k-i}\ i^n=\sum_{i=0}^{k} C_{m}^{i}\ C_{n-m}^{k-i}\ \sum_{j=0}^{i}C_{i}^{j}S_{L}^{j}j!$
然后做和式变换，并且发现有 $C_{m}^{i}C_{i}^{j}$ 用组合数公式处理：
$\Large \displaystyle \sum_{j=0}^{k}C_{m}^{j}\ S_{L}^{j}\ j!\sum_{i=j}^{k} C_{m-j}^{i-j}\ C_{n-m}^{k-i}=\sum_{j=0}^{k}C_{m}^{j}\ S_{L}^{j}\ j!\sum_{i=0}^{k-j} C_{m-j}^{i}\ C_{n-m}^{k-i-j}$

化到这一步$\sum_{i=0}^{k-j}C_{m-j}^{i}\ C_{n-m}^{k-i-j}$ 可以用范德蒙卷积公式变换$C_{n-j}^{k-j}$
$\Large \displaystyle \sum_{j=0}^{k}C_{m}^{j}\ S_{L}^{j}\ j!\ C_{n-j}^{k-j}$
ok ,此时我们就把ksm的时间常数转换成$O(1)$的时间复杂度了，组合数可以用逆元来算，那么斯特林子集数怎么算？
往后唯一的难点在与用NTT求以n为底数的斯特林子集数：这一点我放在【数学讲解\NTT\练习】里面了

细节：
因为这题卡常，所以要对代码进行优化
- 公式里的组合数可以打开，把和 j 无关的项放到后面乘可以减少时间复杂度
- 此时的公式还要算上分母的$C_{n}^{k}$ ，这个同样可以打开与分子做约分。
- NTT的迭代算法中，的R数组放外面，这样可以少做2次运算。
- 将 LL 转换成 int ，注意取模时将所有乘法变成 $((1LL)*a*b)\% mod$ 的形式，外面套的这个括号一定要加。
