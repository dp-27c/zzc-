# 最值贪心法

[Problem - D - Codeforces](https://codeforces.com/contest/2134/problem/D)
大意：
一个树，可以进行这样的操作：
- 选择 a, b, c三个节点，并且满足 b与 a ，c 相连接。
- 将 b 上的边（除了和 a, c连接的边） 全部转移到 c 点上。
使用最少的操作次数，保证最后的树是一条有 n 个节点的链。
请输出第一步，即 第一步的 a b c。若多则一

思路：
碰到这样的题，我们不要被这第一步给迷惑了，仔细模拟一下，就会发现，其实就是要我们去找到能够到达最小操作次数的方法。

 到达最后的方法有很多，如何快速，且有思路的去找到最优呢？

你是不是首先想到，有一条已经存在的最长的链，对，就是树的直径，找到了这条长链。

我们发现长链上总会有其他的一些小长链，而我们最后的结果是一个长度为 n 的大长链。

一次操作后，发现直径可能不变，也可能+1，但是 +2 不太可能，因为从直径的定义和操作，我们不能找到一次就可以使得直径增加2 的方法。

那么我们不妨往这个方向去想，我能不能在已经有的直径的基础上，每一步操作都可以让这个树的直径增加 1，这样就能保证最小操作数了。

思考发现，在直径上的一点，只要找到以直径点为根其不属于这个直径的子点，然后将直径的链连接到那个点上，就可以让那个点成为直径的一部分，然后你就找到了最优方案。
