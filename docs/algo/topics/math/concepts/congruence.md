# 同余

## Bezuot定理(裴蜀定理)

应用：
对于一个 $ax+by=z$，如果 $z$ 是 $a$ 和 $b$ 的最大公约数，那么一定存在整数解 $(x,y)$。
相反，如果存在 $x$ 和 $y$ 是这个式子的整数解，那么可以推出，$z$ 一定是 $\gcd(a,b)$ 的倍数。
忘掉了就给我空降[模版题](https://www.luogu.com.cn/problem/P4549)
对于这个定理的应用我们还可以拓展到 拓展欧几里得定理
