# 距离

## 欧式距离：
到原点的距离(范数为2，n维)

$$
\Large d=(\sum_{i=1}^{n}|x_{i1}-x_{i2}|^{2})^{\frac{1}{2}}
$$

在二维平面两点的距离表达方式是：

$$
\sqrt{(|X_{1}-X_{2}|^2+|Y_{1}-Y_{2}|^2)}
$$

传统意义上的两点之间的距离。

## 曼哈顿距离：
### 概念：

距离公式（范数为 1 ，n维）

$$
\Large d=(\sum_{i=1}^{n}|x_{i1}-x_{i2}|)
$$

在二维平面上，两点之间的距离表达式是

$$
(|X_1-X_2|+|Y_1-Y_2|)
$$

### 性质：
1. 非负性： 曼哈顿距离是一个非负数 
	$d(i,j)\ge 0$
2. 统一性：点到自身的距离为 0
	$d(i,i)=0$
3. 对称性：A 到 B 的距离 和 B 到 A 的距离相等
	$d(i,j)=d(j,i)$
4. 三角不等式：A 到 B 的距离 小于等于 A 经过任何一个点再到 B 的路程之和
	$d(i,j)\le d(i,k)+d(k,j)$
### 练习：
#### 求所有点的最大曼哈顿距离：
大意：
给定 n 个点，求出 任意两点之间的曼哈顿距离的最大值

思路1：
$d=|x_i-x_j|+|y_i-y_j|$
我们不妨令 $x_i>x_j$
分类讨论 $y_i$ 和 $y_j$ 之间的大小关系：
1. $y_i>y_j: d=x_i-x_j+y_i-y_j=(x_i+y_i)-(x_j+y_j)$
2. $y_i<y_j:d=x_i-x_j+y_j-y_i=(x_i-y_i)-(x_j-y_j)$
由此我们发现，统计每个点的 $x_i+y_i$ 和 $x_i-y_i$
分别计算出所有点对应的 最大值 和 最小值 后，比较取大就行了。

这题也开拓出了处理绝对值的思路。

思路2：
曼哈顿距离转切比雪夫距离：
$(x,y) \longrightarrow (x+y,x-y)$
所有坐标转换为 切比雪夫距离表达式，然后切比雪夫距离：
$\max(|X'_1-X'_2|,|Y'_1-Y'_2|)$
所以就是统计最大 和 最小的 $x+y$ 和 $x-y$

代码：（思路1）
```cpp
void solve() // ll
{
    int n;cin>>n;
    int mx1=inf,mi1=INF,mx2=inf,mi2=INF;
    rep(i,1,n)
    {
        int x,y;cin>>x>>y;
        mx1=max(mx1,x+y);
        mi1=min(mi1,x+y);
        mx2=max(mx2,x-y);
        mi2=min(mi2,x-y);
    }
    cout<<max(mx1-mi1,mx2-mi2)<<endl;
}
```

## 切比雪夫距离：
### 概念
n 维空间的切比雪夫距离：
x 和 y  表示两个点的坐标参数。

$$
d(x,y)=\max(|x_i-y_i|)(i\in[1,n])
$$


二维平面上，两点的距离表达式是：

$$
\max(|X_1-X_2|,|Y_1-Y_2|)
$$


## 曼哈顿距离与切比雪夫距离之间的相互转化：
结论：
曼哈顿距离的坐标系是通过切比雪夫距离的坐标系旋转 45 度 并缩小到原来的一半得到的：

曼哈顿距离 转 切比雪夫距离：

$$
(x,y)=(x+y,x-y)
$$

切比雪夫距离 转 曼哈顿距离：

$$
(x,y)=(\frac{x+y}{2},\frac{x-y}{2})
$$


学会在两者之间灵活运用：
注意上面只涉及到二维转换，如果是多维转换，
则曼哈顿的 n 维将转换为 切比雪夫 $2^{n-1}$ 维。
考虑 定第一个 x 坐标轴不变其他的坐标轴参数按照 + 或 - 的二进制表示得到切比雪夫坐标系：
$(x,y,z) \longrightarrow (x+y+z,x+y-z,x-y+z,x-y-z)$
