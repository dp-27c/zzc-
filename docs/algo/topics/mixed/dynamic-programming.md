### 完全背包贪心：

题目：
> *对于一个货币数组a，里面有n种整数货币，求一个长度最小的数组b满足：*
> 1. *b能表示a能表示的所有整数*
> 2. *b不能表示a不能表示的所有整数*

如何思考这是一个完全背包的题目呢？
首先 需要证明，最优的方案中，b一定是a的子集；
然后 找到a的元素中被表示的方案 不只自己1种 的 元素可以被删掉；


### 背包排序贪心：

题目：
> 有n个石头，在第j秒吃掉第i个需要s时间，获得e-j * l  的能量，问最多能获得多少能量

思路：
意思是 比较两个相邻的石头 i 和 i+1不同吃的顺序所获得的能量。
1. 先吃i，     `e[i]+e[i+1]-s[i]*l[i+1]`;
2. 先吃i+1，`e[i+1]+e[i] -s[i+1]*l[i]`;
所以比较相邻的最优顺序，排序即可贪心出最优路线！！
然后就是01背包问题。具体细节请看代码注释。

### 背包不选第 i 个物品

[# Eden 的新背包问题](https://www.luogu.com.cn/problem/P4095)
大意：
给n个物品，每个物品有其价值，价格，数量；
q次询问，每次给物品 id 和 总钱 m
求在不选择 第 id 个 物品的前提下，用 m 钱能买的最大价值
思路：
首先是一个多重背包模版
如何考虑 不选择 id 物品的前提下呢，
正常的 多重背包 `f[i][j]`表示考虑前 i 的物品 j 钱的最大价值
那么 `f[i-1][j]` 表示不选择 i 考虑前i -1 的最大价值，但没考虑到 i+1 往后的物品
所以我们需要两个背包，按照物品排列，一个正着考虑，一个反着考虑；
然后 遍历 j 表示给正序 `f1[i-1][j]` 的钱，那么取最大的`f1[i-1][j]+f2[i+1][m-j]`
注意：
因为要考虑时间复杂度，所以要对多重背包进行优化，我用的是单调队列优化，要对单调队列的细节掌握清楚；
也可以用二进制优化，但是 在考虑不选择第 id 个物品时，连着它所拆解的二进制数加以考虑；

## 状压dp：

### 分组背包+二进制转移

[梦幻岛宝珠](https://www.luogu.com.cn/problem/P3188)
题意：
n个宝珠，每个宝珠对应一个重量和价值，问你用最大称重m的背包能装最大价值为多少？
每个宝珠的重量在 $1$ 到 $2^{30}$ 的范围，且每个重量可以变成 $a\cdot 2^b$ 的形式
思路：
因为重量开的范围太大，直接用板子会超时
所以我要考虑利用题意第二行 的信息
先将每个 物品的 V 转成 `{a,b}` 的形式，意为 $a\cdot 2^b$
然后对于每个有着相同的2的指数的物品，先做01背包处理，得到32个不同的01背包；
然后考虑如何合并，这些背包，考虑状态压缩
`f[i][j]`表示 背包2指数为i的，乘上j的背包最大价值
状态转移：`f[i][j]=max(f[i][j-k]+f[i-1][2*k+(m在i-1位上的数字)]  (k-> (0,1000))`
为什么后面要加上关于m的这个数，原来如果m那个位上有1的话，按照2*k的方法转移是不能消去这个1的，所以要补1才能消掉
最后访问 `f[m最高位1的位置][1]`
对于m而言，先将他拆成二进制的形式

### 二叉树的区间dp（dfs，记忆化，区间dp）

[加分二叉树](https://www.acwing.com/problem/content/481/)
主要练习如何把一个二叉树的中序遍历看成是一个区间dp的问题；
题意：
> 一个n个节点，第`i`个节点的分数为`a[i]`，且满足中序遍历 123456...n
> 对于一个根节点的分数=左子树的分数 * 右子树的分数 + 根节点自己的分数
> 若一个根节点不是叶子节点且有一边子树为空，那么空子树分数按1来算
> 求可以形成的最大分数，且输出满足这个条件的树的前序遍历，且满足字典序最小

思路：

枚举区间长度
枚举以中序遍历的一个区间长度作为子树长度，遍历该区间的节点，以这个节点为根的情况下，分数为多少。
用另一个二维数组保存区间最优根节点。
寻找最优路径直接dfs加最优根节点的信息去找。

```cpp
    vii dp(n+2,vi(n+2,1));
    vii p(n+2,vi(n+2,0));
    //p保存最优根节点的位置；
    rep(len,1,n)
    {
        for(int l=1,r=1;r<n;++l)
        {
            r=l+len-1;
            if(l==r){dp[l][r]=a[l],p[l][r]=l;continue;}
            rep(k,l,r)
            {
                int w;
                if(k-1<l) w=dp[k+1][r]+a[k];
                else if(k+1>r) w=dp[l][k-1]+a[k];
                else w=dp[l][k-1]*dp[k+1][r]+a[k];
                if(w>dp[l][r])
                {
                    dp[l][r]=w;
                    p[l][r]=k;
                }
            }
        }
    }
    cout<<dp[1][n]<<endl;
    vi ans;
    //dfs为找到前序遍历；
    function<void(int,int)> dfs=[&](int l,int r)
    {
        if(l>r) return;
        ans.push_back(p[l][r]);
        dfs(l,p[l][r]-1);
        dfs(p[l][r]+1,r);
    };    
```

### 区间dp+dfs遍历

题意：
[# CF149D Coloring Brackets](https://www.luogu.com.cn/problem/CF149D)
一个配对括号字符串s
配对的括号只能染一边，且一边只能染红或蓝
不允许有相邻字符染同一种颜色的情况。
问合法方案数。
思路:
对于这样的合法括号问题，我们需要先对字符串进行遍历，即找到右括号匹配的左括号的位置`p[r]`
然后用区间dp的思路进行`dfs(l,r)` 遇到匹配的括号则往下遍历`dfs(l+1,r-1),`否则就遍历`dfs(l,p[r]-1),dfs(p[r],r);`
对于一对匹配的括号只有四个状态，所以我们很容易被误导；
在dfs的区间遍历过程中，一段区间的最外围的括号不一定是合法括号，所以一共有9种状态
别忘了当区间达到最小值是给这单个括号赋一个匹配括号的初值1
设立`f[l][r][id]` 根据条件去判断dp就可以了
不足：状态 转移的过程过于繁琐，应该用二位三进制去判断更加可靠；

### 字符串区间染色问题：

[# UVA1437 String painter](https://www.luogu.com.cn/problem/UVA1437)（洛谷紫）
大意：
给定两个的字符串，A和B，问将A染色成B最少次数，你可以选择A的任何子串染成同一个字符。
思路：
这比空白染色的难度在于可能有相同的字符干扰。
空白染色的思路在于特判`s[l]==s[r]`时，`dp[l][r] `可以等于`dp[l-1][r]或dp[l][r-1]，`
如果有 `(l,r)` 相同子串染色，那么他的染色方式可能是 `dp(1,l-1)+dp(r+1,n)`。
所以我们先将他当成空白染色来做，然后再对从前往后的每一段相同子串进行特判，更新包含相同子串的区间。
于是我们就可以得到考虑到所有方案的最优解。
下面的dp是对我繁琐的相同子串特判的优化；
根据染色方式分类，先判空色染色方式，再判特殊染色方式。
即
设立一个`g[i]`表示考虑特判后`(1,i)` 的最小次数，考虑每个区间是否选择用特判的方法连起来
这样的线性dp要比我的分段特判轻松很多

## 思维dp：

### 跳出序列算贡献：

[Problem - D - Codeforces](https://codeforces.com/contest/2119/problem/D)
大意：
对于一个序列，满足坐标为 $i$ 的值小于等于 $i$，即 $a_i\le i$。
对于长度为 n 的序列来说，每个坐标都有一个令牌，按照索引从1 -> n 的顺序，第 i 个值可以取序列中`[a[i],i]`的其中一个令牌。
令牌只能被取走一次，且如果 $a_{i}$ 为 0 的话，则不能取任何令牌。
求对于一共 $(n+1)!$ 种不同序列，每个序列有 $k$ 种不同令牌取走顺序，求所有序列的 $k$ 之和。
思路：
要跳出对一个一个确定的序列算方案，因为这样整合要考虑的因素太多了，还要考虑令牌方案重合的问题
所以我们要以令牌取走的方案顺序为参考，判断这个顺序有多少种不同的序列。
因为越往后，受到的限制越大，即后面的令牌只能被后面和更后面的索引拿走，所以我们尝试从后往前遍历。
对于索引 i 来说，假设后面已经有 j 个索引取过了 ，我们设立状态 `f[i][j]`来表示.
此时就是 $i$ 这里的令牌是被谁取走的？可以是不取走（$a_i=0$）或者是被后面 $j$ 个拿走的（$f[i][j-1]\cdot C_{\mathrm{num}}^1\cdot i$）
num 表示 后面除了已经取走的 j - 1 个位置以外，还剩的位置都有可能取走 i ，这个取走 i 的位置的值的可能 有 （1->i) 共 i 种。
这样做 后缀 dp 就可以了，其实有点像是背包。

### 序列重合导致重复计算：

[Problem - F1 - Codeforces](https://codeforces.com/contest/2124/problem/F1)
大意：
选择一个整数 $s\ge 1$，并在 $a$ 的末尾加上数组 $[1,2,\ldots,s]$ 的循环移位。正式地，选择 $s$ 和 $r$ 这样的整数 $1\le r\le s$，并追加数组：

$$
[r,r+1,\ldots,s,1,2,\ldots,r-1]
$$

你的任务是计算长度恰好为 n 的不同数组的个数，这些数组可以使用允许的操作构造并满足所有给定的限制。如果两个数组在 1 到 n 之间的任何位置不同，则认为它们是不同的。
以 998244353 为模打印答案。
n≤100
思路：
设 `f[i][j]` 表示 到 第 i 位置 且上一段长度为 j 的 方案个数 ，然后 设 k 判断 i - j + 1到 i 这段的合法性。
合法则加上 `s[i-j]` （ `s[i]` 为前 i 位置合法的法案总和 ）
最后输出 `s[n]`
那么 故事到这里就结束了吗？  of course not！！！

我们发现 若序列出现 :

$$
[1,2,3,4,\ldots,n],[n+1,n+2,\ldots,m,1,\ldots,n]
$$

$$
[1,2,3,4,\ldots,n,n+1,n+2,\ldots,m],[1,\ldots,n]
$$

我们将这里计算多了一次，所以在面对这类情况要特判！！
设 t 为每次 多算的部分，在本身合法的情况下，如果存在 上一个是 n-1结尾的，且这一次是 n+1开头的，则 t 加上`s[i-j-(k-1)]`，`s[0]`除外

但是还是会wa_6，debug，发现我们并没有判断 存在 上一个是 n-1结尾的这种情况的合法性，所以用bool值的三维数组判断这段是否合法。
总体没错，但是代码不如其他人的简单明了。

#### 剪枝，纯粹的暴力美学

大意：
Rainbow 把一副扑克牌(54 张)随机洗开，倒扣着放成一摞。

然后 Admin 从上往下依次翻开每张牌，每翻开一张黑桃、红桃、梅花或者方块，就把它放到对应花色的堆里去。

Rainbow 想问问 Admin，得到至少 A 张黑桃、至少 B 张红桃、至少 C 张梅花、至少 D 张方块需要翻开的牌的张数的期望值 E 是多少？

特殊地，如果翻开的牌是大王或者小王，Admin 将会把它作为某种花色的牌放入对应堆中，使得放入之后 E 的值尽可能小。

由于 Admin 和 Rainbow 还在玩扑克，所以这个程序就交给你来写了。

思路：
设置状态 `f[a][b][c][d][x][y]` 分别表示摸到 a 个 A类  ， b 个 B 类牌…… 以及大王小王处在哪一类牌的位置（包括没有摸到）；

首先从 0 0 0 0 0 0 的状态开始摸牌，每次摸牌本身的次数是1 ，模拟下一次摸牌的结果，加上下一次摸牌的期望。

剪枝时候注意边界问题以及记忆化问题。

每次如果大王小王没有摸到时，还要有一步摸到大小王的期望，为了实现最小的摸牌次数的期望，在摸到大小王的时候，把他们放到四个位置都试一遍，最后取期望最小的那个就可以了，这是一步需要注意的贪心。
