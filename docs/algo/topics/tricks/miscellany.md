# 杂论

## 中位数：
1. 一个数组的中位数判断可以二分枚举一个数值，然后与每个元素做对比，比他大的标记为1，小的标记为-1，所有标记求和后 二分搜索左右两侧的。

## 生成函数的构造：
### 判断偶数长度的区间是否可以2个一对，每队和相同
首先求出区间平均值 c。
然后直接判断 对于区间内任意 $i$，判断 $cn_{c+a_i}=cn_{c-a_i}$。
对此为了快速判断，我们可以构造普通生成函数：

$$
f_{+}(x)=\sum_{i=-\infty}^{\infty} cn_{i} \ x^{+i}
$$

为了满足 条件判断：$f(c+i)==f(c-i)$，考虑构造：
$f_{+}(i)\times x^{-c}$ 这个式子的含义表示，所有 $cn_{c+i}$ 对应的 $x^{c+i}$ 变成了 $x^{i}$
$f_{-}(i)\times x^c$  这个式子的含义表示，所有$cn_{c-i}$ 对应的 $x^{c-i}$变成了$x^{-i}$
因此 满足 $f_{+}(i)=x^{2c}\times f_{-}(i)$
取随机数 x ，并维护 平均值 c ，$\displaystyle f_{+}(i)=\sum_{i=l}^{r}x^{a_i},f_{-}(i)=\sum_{i=l}^{r}x^{-a_i}$

## bitset构造：
### 判断区间是否存在两个数的差为 c
对于区间维护 bitset bt
`bt[i]` 表示 第i个数是否存在。
令一个新的 bitset 为 bt2 等于 bt << c
此时 `bt2[i]` 表示第 i - c 是否存在。
将 bt & bt2  最后判断这个数是否为 全0，否则存在 差为 c。

### 判断区间是否存在两个数 和为c
对于区间维护还是 bitset bt
`bt[i]` 表示 第i个数是否存在。
同时维护一个bitset 为 `rbt[i]` 等于 第 N - i 数是否存在
将 rbt >> cha (N - c),表示 `rbt[i]` 等于 第 N -（i + cha）也就是 c - i
bt & (rbt>>cha) 是否为全0，否则存在 和为 c。
